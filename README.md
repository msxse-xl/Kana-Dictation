## 这是什么

这是一个简单的日语假名听写工具：

- 选择想练的行
- 点击开始，假名会随机出现并被朗读
- 朗读结束后，留出你自定义的书写时间
- 在纸上写下听到的假名
- 最后对照答案，点任意假名还能重听

所有音频、样式和逻辑都打包在一个 **约 1.4 MB 的 HTML 文件**里。不需要安装，不需要联网，双击就能用。

## 功能

- **71 个假名**：清音 46、浊音 20、半浊音 5
- **按行选择范围**：あ行、か行、さ行……直到 ぱ行；也可以快捷选择清音 / 浊音 / 半浊 / 全选 / 清空
- **随机听写**：开始后自动打乱顺序；也可以关闭随机，按五十音顺序播放
- **自定义停顿**：1–20 秒，精确到 0.5 秒。朗读结束后才开始倒计时，留出足够的书写时间
- **双声优**：日语女声（Nanami）与男声（Keita）
- **朗读 1 遍 / 2 遍**：默认 2 遍，可在设置里改成 1 遍
- **语速调节**：0.7×–1.3×
- **罗马音提示**：朗读结束后，在屏幕中央显示对应的罗马音（如「か」显示 `ka`），可在设置中关闭
- **完整控制**：暂停 / 继续、重听当前音、跳到下一个、提前结束
- **答案核对**：按实际播放顺序显示平假名、片假名、罗马音和所属行，点击任意答案可重听
- **离线可用**：发音已内嵌到 HTML，不联网也能使用；不上传任何数据
- **设置记忆**：范围、停顿、声音、语速、主题等会自动保存在浏览器本地
- **手机专注模式**：手机上开始听写后自动隐藏设置，只保留听写界面
- **深浅色主题**：支持手动切换

## 快速开始

1. 下载 **[五十音听写.html](五十音听写.html)**（如果在 GitHub 上打开的是源码页，点击右上角 **Download raw file**）。
2. 用 **Edge** 或 **Chrome** 打开这个 HTML 文件。
3. 在左侧勾选想练的行，设置停顿时间和声音。
4. 点击「开始听写」，准备纸笔，听到读音后写下假名。
5. 结束后在答案页核对；点击答案可以重听。

更详细的操作说明见 **[使用说明.md](使用说明.md)**。

### 快捷键

| 按键 | 功能 |
| --- | --- |
| `空格` | 开始 / 暂停 / 继续 |
| `R` | 重听当前音 |
| `N` | 下一个音 |
| `Esc` | 结束本次听写 |

## 关于同音假名

日语里有几组假名发音相同：

- `を` 与 `お`
- `ぢ` 与 `じ`
- `づ` 与 `ず`

听写时如果听到同音，写出其中任意一个都算听对了音；答案页会标注「同音」，方便对照。

## 技术实现

- 纯 **HTML + CSS + JavaScript**，没有运行时框架
- 音频为 **284 段内嵌 MP3**：71 个假名 × 2 个声优 × 1 遍 / 2 遍
- 使用浏览器的 `Audio` API 顺序播放，`requestAnimationFrame` 驱动停顿倒计时
- 使用 `localStorage` 保存设置
- 最终产物是单个 HTML 文件，适合直接分享、离线使用或部署到 GitHub Pages

### 项目结构

```text
.
├── 五十音听写.html          # 最终产物：单文件应用

```

### 本地构建

只重新打包（不需要联网，使用仓库里已有的音频）：

```bash
python build.py
```

重新生成音频（需要 Python、`edge-tts`、`ffmpeg` 和网络）：

```bash
python -m pip install edge-tts
python tools/build_audio.py
python build.py
```

## 已知限制

- 发音为神经语音合成，适合做听写练习，不替代真人录音
- 内置的是五十音 / 浊音 / 半浊音，不包含拗音、长音、促音等扩展内容
- 没有自动判分：答案页用于自己核对
- 停顿上限为 20 秒
- 设置保存在当前浏览器里，不会跨设备同步
